# 👑 TAÇ AI | VIP Yapay Zeka Ajansı

Taç AI, kurumlar ve işletmeler için özel otonom yapay zeka ajanları, kurumsal RAG (Bilgi Bankası) çözümleri ve süreç otomasyonları sunan üst düzey yapay zeka ajansının resmi web sitesidir.

## 🚀 Öne Çıkan Özellikler

- **Obsidian VIP Tasarım:** Modern cam efektleri (glassmorphism), neon ışıklandırma detayları ve mobil uyumlu arayüz.
- **Canlı ROI Hesaplayıcı:** Kurumsal müşterilerin otonom ajan entegrasyonu ile elde edeceği yıllık maliyet tasarrufunu anlık hesaplama.
- **Otonom AI Terminali:** Müşterilerin yapay zeka senaryolarını test edebileceği etkileşimli simülasyon alanı.
- **Yüksek Performans:** Sıfır derleme süresi ve hızlı CDN altyapısı ile kesintisiz erişim.

## 🛠️ Teknoloji Yığını

- **Frontend:** HTML5, Tailwind CSS, Lucide Icons
- **Deployment:** Vercel (7/24 Kesintisiz Yayın)
- **AI Mimarisi:** Python, LangChain, CrewAI
